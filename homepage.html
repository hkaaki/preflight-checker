Check before you trust it.

If you're building or running an AI agent, it sometimes has to decide whether to trust something before acting on it: a code library it's about to install, another API it's about to call, a website it's about to visit. Four quick checks answer that in seconds, for a few cents each.

Before you run someone's code

Check whether an npm package is what it claims to be, not a copycat with a similar name, before your agent installs it.

Before you trust another service

Check whether a GitHub project is actively maintained, or whether a domain is even live, before you build on top of it.

Before you go live yourself

If you're running your own x402 service, find out why buyers or directories might see it as broken, and the exact fix.

Try it

Run this, swapping in any real npm package name:

$ curl "x402-api-catalog.onrender.com/api/trust-check?package=left-pad"
< {"package": "left-pad", "score": 70, "verdict": "trustworthy", "reasons": [...]}

The first response asks for two cents in USDC on Base. Any x402-capable client (like awal) handles that automatically and hands back the real result above.
