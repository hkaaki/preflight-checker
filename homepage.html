x402-api-catalog live on Base mainnet

Four real APIs.
Pay in USDC. No signup.

A working example of the internet's oldest unused HTTP status code, finally doing its job. Send a request, get a 402, pay it, get your answer — in the same call.

$ curl x402-api-catalog.onrender.com/api/trust-check?package=left-pad
< HTTP/1.1 402 Payment Required
< payment-required: accepts=[{scheme:"exact", asset:"USDC", amount:"20000", payTo:"0x9041...847E"}]
$ curl x402-api-catalog.onrender.com/api/trust-check?package=left-pad \
-H "PAYMENT-SIGNATURE: <signed>"
< HTTP/1.1 200 OK
< {"package":"left-pad","score":70,"verdict":"trustworthy","reasons":[...]}

Endpoints

GET /api/trust-check $0.02 npm package trust check: registry age, weekly downloads, GitHub org/stars, OSV.dev vulnerabilities, typosquat detection.
GET /api/repo-health $0.02 GitHub repo health: stars, forks, open issues, last commit age, archived status, license.
GET /api/domain-check $0.02 Domain liveness: DNS resolution, mail routing, HTTP reachability.
GET /api/x402-doctor $1.00 Audits another x402 service — why aggregators mark it "down," and the exact fix.
